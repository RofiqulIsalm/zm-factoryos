============================================================
1. VERY IMPORTANT DEVELOPMENT RULE
============================================================

BUILD FROM SCRATCH.

Do NOT copy the architecture of an existing application.

Do NOT blindly generate a generic SaaS admin template.

Do NOT create fake-looking dashboards with static numbers.

Do NOT hardcode business data into UI components.

Do NOT use mock data as the permanent implementation.

Create a real database-backed application.

Every important number shown in dashboards must eventually come from
the database.

Every important button must perform a real action.

Every form must save real data.

Every workflow transition must be recorded.

Every user must have proper authentication and authorization.
